# ระบบจองที่นั่ง — ห้องเอนกประสงค์ คณะรัฐศาสตร์ ม.บูรพา

เว็บจองที่นั่ง (โซฟา/โต๊ะ/บาร์) พื้นหลังสีขาวครีม สถานะสีเขียว = ว่าง, แดง = ไม่ว่าง แบบเรียลไทม์
ต้องกรอกรหัสนิสิตตอนจอง และใช้รหัสเดิมยืนยันตอนยกเลิก
ใช้ **Vite + React** เป็น frontend และ **Supabase** เป็นฐานข้อมูล แล้ว deploy บน **Vercel**

คู่มือนี้เริ่มจากศูนย์ทั้งหมด (โปรเจกต์ Supabase ใหม่ + repo GitHub ใหม่ + โปรเจกต์ Vercel ใหม่)

---

## ขั้นตอนที่ 1 — สร้างฐานข้อมูลบน Supabase (ฟรี)

1. ไปที่ https://supabase.com แล้วสมัคร/ล็อกอิน กด **"New project"**
2. ตั้งชื่อโปรเจกต์อะไรก็ได้ เลือกรหัสผ่านฐานข้อมูล (เก็บไว้เผื่อใช้ภายหลัง) รอสักครู่จนโปรเจกต์พร้อมใช้งาน
3. ไปที่เมนู **SQL Editor** (ไอคอนรูป `>_` แถบซ้าย) → กด **"New query"**
4. เปิดไฟล์ `supabase.sql` ในโฟลเดอร์นี้ → คัดลอกทั้งหมด → วางในช่อง SQL Editor → กด **Run**
   - ถ้าบรรทัดสุดท้าย (`alter publication supabase_realtime add table bookings;`) รันไม่ผ่าน ไม่ต้องกังวล ให้ไปที่เมนู **Database → Replication** แล้วเปิด (toggle เป็นสีเขียว) ตาราง `bookings` แทน
5. ไปที่เมนู **Project Settings** (ไอคอนเฟือง มุมล่างซ้าย) → **API Keys**
6. คัดลอกค่า 2 อย่างเก็บไว้:
   - **Publishable key** (ขึ้นต้นด้วย `sb_publishable_...`) → นี่คือ `VITE_SUPABASE_ANON_KEY`
   - ไปที่เมนู **General** ในหน้า Settings เดียวกัน → คัดลอก **Project ID** แล้วประกอบเป็น URL เอง:
     ```
     https://<Project ID>.supabase.co
     ```
     นี่คือ `VITE_SUPABASE_URL`

---

## ขั้นตอนที่ 2 — สร้าง Repository ใหม่บน GitHub

1. ไปที่ https://github.com → กด **"New repository"**
2. ตั้งชื่อ repo เช่น `Polsci-Multi-Room` → เลือก **Public** หรือ **Private** ก็ได้ → กด **"Create repository"**
3. จะได้หน้าว่างเปล่าพร้อมคำสั่ง git ให้ทำตาม (ใช้ GitHub Desktop จะง่ายกว่า ดูขั้นตอนที่ 3)

---

## ขั้นตอนที่ 3 — อัปโหลดไฟล์โปรเจกต์ขึ้น GitHub ด้วย GitHub Desktop

1. เปิด **GitHub Desktop** → เมนู **File → Clone Repository** → เลือก repo ที่เพิ่งสร้าง (`Polsci-Multi-Room`) → เลือกตำแหน่งเก็บไฟล์บนเครื่อง → กด **Clone**
2. เปิด **Finder** ไปที่โฟลเดอร์ `Polsci-Multi-Room` ที่เพิ่ง clone มา (โฟลเดอร์นี้จะว่างเปล่า)
3. เปิดโฟลเดอร์นี้ (ที่ผมส่งให้) คู่กัน → เลือกไฟล์และโฟลเดอร์ทั้งหมดข้างใน (Cmd+A) → คัดลอก (Cmd+C)
4. วางลงในโฟลเดอร์ `Polsci-Multi-Room` ที่ clone มา (Cmd+V)
5. กลับไปที่ GitHub Desktop จะเห็นไฟล์ทั้งหมดขึ้นในแท็บ **Changes**
6. ใส่ข้อความใน **Summary** เช่น `initial commit`
7. กด **Commit to main**
8. กด **Push origin**

รีเฟรชหน้า GitHub ดู ควรเห็นไฟล์ทั้งหมดขึ้นแล้ว

---

## ขั้นตอนที่ 4 — Deploy บน Vercel

1. ไปที่ https://vercel.com → ล็อกอินด้วยบัญชี GitHub เดียวกัน
2. กด **"Add New" → "Project"**
3. ถ้ายังไม่เคยเชื่อม ให้กด **"Continue with GitHub"** แล้ว **Install** ให้สิทธิ์เข้าถึง repo (เลือก "All repositories" หรือเลือกเฉพาะ `Polsci-Multi-Room` ก็ได้)
4. หา repo **`Polsci-Multi-Room`** ในรายการ → กด **Import**
5. ในหน้า Configure Project เลื่อนหาส่วน **"Environment Variables"** แล้วเพิ่ม 2 ตัวนี้:

   | Key | Value |
   |---|---|
   | `VITE_SUPABASE_URL` | ค่าที่คัดลอกจากขั้นตอนที่ 1 |
   | `VITE_SUPABASE_ANON_KEY` | ค่าที่คัดลอกจากขั้นตอนที่ 1 |

6. กด **"Deploy"** รอประมาณ 1 นาที

พอเสร็จจะได้ลิงก์เว็บ เช่น `https://polsci-multi-room.vercel.app` — เปิดลิงก์ที่ไม่มีรหัสแปลกๆ ต่อท้าย (อันที่ระบุว่า **Production**) เพื่อดูผลลัพธ์

## กติกาของระบบ

- **ยืนยันการมาถึง:** เมื่อถึงเวลาจอง ผู้จองต้องกดปุ่ม "ยืนยันการมาถึง" (ในหน้าต่างของที่นั่งนั้น) แล้วใส่รหัสนิสิตที่ใช้ตอนจอง ภายใน 10 นาทีหลังเวลาเริ่ม (ถ้ากดจองหลังเวลาเริ่มไปแล้ว จะนับ 10 นาทีจากเวลาที่กดจอง) ถ้าไม่ยืนยันทันเวลา การจองจะถูกลบอัตโนมัติและที่นั่งกลับเป็นสีเขียว
- ระหว่างรอยืนยัน ที่นั่งจะเป็นสีแดงและมีข้อความ "รอยืนยัน"
- **จองได้ครั้งละไม่เกิน 3 ชั่วโมง** เพื่อให้ทุกคนได้ใช้โต๊ะอย่างเท่าเทียมกัน ถ้าต้องการใช้งานต่อให้จองอีกครั้ง (แก้จำนวนชั่วโมงได้ที่ตัวแปร `MAX_BOOKING_HOURS` ใน `src/App.jsx`)
- **ล้างข้อมูลการจองทั้งหมด:** ต้องใส่รหัสผ่านผู้ดูแล และรหัสเดียวกันนี้ใช้ยกเลิกการจองของคนอื่นได้ด้วย (ตั้งไว้ที่ตัวแปร `ADMIN_PASSWORD` บนสุดของไฟล์ `src/App.jsx` เปลี่ยนได้)
- **ปิดเว็บชั่วคราว:** เปลี่ยน `SITE_CLOSED` เป็น `true` ในไฟล์เดียวกัน แล้ว Commit + Push เว็บจะแสดงหน้า "ปิดให้บริการชั่วคราว" ข้อมูลการจองยังอยู่ครบ เปลี่ยนกลับเป็น `false` แล้ว Push อีกครั้งเพื่อเปิด
- **การแจ้งเตือน:** (1) ถ้าเปิดเว็บค้างไว้ในเครื่องที่ใช้จอง จะมีแถบเตือนก่อนถึงคิว 10 นาที และตอนถึงเวลาให้ยืนยันการมาถึง (2) ผู้จองเลือกรับแจ้งเตือนผ่าน LINE Official Account ได้ตอนจอง ผู้จองและแอดมินที่ลงทะเบียนไว้จะได้รับข้อความก่อนถึงคิว 10 นาที และตอนถึงเวลา ต้องตั้งค่าตามไฟล์ `LINE-SETUP.md` ก่อน แล้วเปลี่ยน `LINE_ENABLED` เป็น `true` ใน `src/App.jsx`
- เวลายืนยัน (10 นาที) แก้ได้ที่ตัวแปร `GRACE_MIN` ในไฟล์เดียวกัน

### ถ้าเคยรัน supabase.sql เวอร์ชันเก่าไปแล้ว
เปิด Supabase → SQL Editor → วางเนื้อหาไฟล์ `supabase-migration-add-confirmed.sql` → Run **ก่อน** อัปเดตโค้ดขึ้น GitHub (การจองเดิมทั้งหมดจะถือว่ายืนยันแล้ว ไม่ถูกลบ)

## อัปเดตเว็บในอนาคต

ทุกครั้งที่แก้โค้ด แค่ทำซ้ำขั้นตอนนี้:
1. แก้ไฟล์ในโฟลเดอร์ที่ clone มา
2. เปิด GitHub Desktop → ใส่ Summary → Commit → Push origin
3. Vercel จะ build และ deploy เวอร์ชันใหม่ให้อัตโนมัติภายในไม่กี่นาที ไม่ต้องตั้งค่าอะไรซ้ำ

---

## ข้อควรทราบเรื่องความปลอดภัย

- เว็บเปิดให้ทุกคนจองได้โดยไม่ต้องล็อกอิน ต้องกรอกรหัสนิสิตตอนจอง และใช้รหัสเดิมยืนยันตอนยกเลิก — ป้องกันคนทั่วไปกดยกเลิกของคนอื่นมั่วๆ ผ่านหน้าเว็บ แต่รหัสเก็บแบบข้อความธรรมดา ไม่ได้เข้ารหัส ไม่ใช่ระบบความปลอดภัยระดับสูงสุด
- ถ้าอยากได้ระบบที่รัดกุมกว่านี้ในอนาคต (เข้ารหัสรหัสผ่าน, ผูกกับระบบล็อกอินนิสิตจริง, จำกัดสิทธิ์แอดมิน) แจ้งได้เลยครับ
